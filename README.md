# Evidence Practice Proof

A functional MVP for comparing expected practice with observed event records.

## MVP functionality

- Define expected practice
- Load observed CSV events
- Group events by case
- Detect missing activities
- Detect unexpected activities
- Calculate a transparent fidelity signal
- Show results per case

## CSV format

CaseId,Timestamp,Activity,PerformedBy

## Interpretation boundary

A structural mismatch is not automatically evidence of poor care,
causality, clinical ineffectiveness, misconduct, non-compliance
or regulatory breach.

Synthetic development data only.

## Run

Open `index.html` in a browser.
