# Academic Research Engine

Standalone reusable research engine for academic research, evidence-based practice and source-grounded AI. Designed to integrate into the Complete Evidence Appraisal Tool and other applications.

## Core capabilities
- research document workspace
- source search with provenance
- PDF/DOCX/TXT extraction in the host application
- source-grounded AI Q&A contract
- evidence claim tracking
- verification states
- APA 7 and Vancouver citation formatting
- HTTP integration API
- reusable TypeScript services

## Integrity model
AI output is candidate output. It does not automatically establish publication validity, evidence certainty, study quality or appraisal decisions. Evidence remains linked to an explicit document and location.

## Integration
The engine is deliberately independent of AMSTAR 2, CASP, JBI, AGREE II, RoB 2, GRADE and other appraisal domains, allowing the same research layer to be embedded in multiple products.
