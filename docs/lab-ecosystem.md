# Lab ecosystem

This repository is the **Evidence Lab** node in the broader Lab ecosystem.

```text
LAB CORE
   │
   ├── Game Lab        → algorithms, AI, state
   ├── Evidence Lab    → appraisal, synthesis, traceability
   ├── Security Lab    → auth, crypto, protocols
   ├── Data Lab        → SQL, pipelines, validation
   ├── DevOps Lab      → CI/CD, deployment, resilience
   └── Systems Lab     → WASM, workers, systems
```

The Lab concept is shared across the portfolio, while each repository remains independently implemented and testable.

## Evidence Lab

**Repository:** `abla86/complete-evidence-appraisal-tool`

Focus:

- critical appraisal
- evidence verification
- study-design routing
- dual review
- traceability
- synthesis support
- implementation support
- export and audit evidence

The Evidence Lab is not a generic software demo: methodological claims remain distinct from software correctness and deployment status.
