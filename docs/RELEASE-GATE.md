# Evidence — release gate

Evidence is treated as a private/proprietary research application. The following are release blockers:

1. The authoritative workflow must compile and pass automated tests.
2. AI-generated candidates must remain unverified until human review.
3. Screening must be explicitly included before appraisal.
4. Appraisal sessions must use the selected instrument and reviewer identity.
5. Locked appraisal sessions are required before project export.
6. Project scope must prevent cross-project evidence access.
7. Instrument metadata must retain source/version provenance; unverified claims must not be presented as verified methodology.
8. Demo/sample records must be visibly distinguishable from researcher data.
9. CI must provide a successful result before a release is declared production-ready.

This document is a release contract, not a claim that the current revision has passed every gate.
