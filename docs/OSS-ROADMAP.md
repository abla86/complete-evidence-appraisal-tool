# Open-source roadmap

This repository is maintained as a public evidence-appraisal platform rather than a portfolio-only demonstration.

## Priority order

1. Keep production build, tests, Docker build and security workflows reliable.
2. Remove remaining TypeScript type debt and mojibake/encoding corruption.
3. Preserve explicit methodology versions and provenance for every appraisal workflow.
4. Expand automated contract tests before adding new methodology modules.
5. Keep the Academic Research Engine integration stable through the documented handoff contract.
6. Add contributor-friendly issues with focused scopes and reproducible acceptance criteria.

## Contribution areas

- TypeScript/React reliability
- test coverage and contract testing
- accessibility and UX
- evidence provenance and auditability
- methodology versioning
- import/export interoperability
- CI/CD and supply-chain security
- documentation and reproducibility

## Non-goals

AI must not silently make appraisal decisions, fabricate evidence, or replace methodological review. New automation must preserve human verification and an inspectable audit trail.
