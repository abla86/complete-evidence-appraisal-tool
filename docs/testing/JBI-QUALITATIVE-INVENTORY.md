# JBI Qualitative Feature Inventory

This inventory is the preservation contract for the existing Evidence Tool JBI Qualitative appraisal surface.

## Existing application surface

- JBI Qualitative (2017) instrument selection
- Article library / overview
- Research search & databases
- Article details & evidence
- JBI assessment form
- Dual review / comparison
- Peer review & groups
- Methods synthesis & assignment text
- Audit trail
- Methodical control / WHO validation
- Research-on-research / integrity watch
- Reference library
- Validation dashboard
- Source & methodology audit
- Help & example library
- Instrument information
- Document analysis modal
- Universal import/export hub
- Autosave / snapshots / restore
- GDPR & privacy center
- Evidence location and rationale capture
- Article lifecycle and reviewer role handling
- No destructive duplicate deletion
- Qualitative whole-assessment interpretation rather than unsupported numeric total scores
- QARI-style qualitative evidence grading concepts

## Methodological preservation rules

- Do not replace the existing JBI qualitative workflow with a generic score-only model.
- Do not remove evidence-location, rationale, audit, reviewer, or instrument-version context.
- Do not silently upgrade detected metadata to verified evidence.
- Do not silently delete duplicate research records.
- Keep historical instrument versions immutable for existing assessments.
- New superprogram capabilities must be additive and use explicit `ActiveTab` integration rather than replacing the existing application shell.
