# LEGACY — Academic Research Engine

This repository is retained as historical implementation work only.

## Canonical destination

Research/evidence functionality belongs in [`complete-evidence-appraisal-tool`](https://github.com/abla86/complete-evidence-appraisal-tool).

The engine provided reusable document extraction, research workspace, source-grounded Q&A, provenance, evidence claims, citation formatting, DOI/PMID metadata, and HTTP/TypeScript services. Those capabilities are conceptually aligned with the canonical evidence platform and should not be maintained as a competing standalone product.

AI output remains candidate output and human verification remains required.
